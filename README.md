# One Word, One Username, One Reward — rinoo9

Entry for the [make.fun bounty "One Word, One Username, One Reward"](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The entry is the entrant's own username, one word and nothing else:
`rinoo9` — 6 characters, no explanation, no links, no pitch.

## How it works

`main.py` is deterministic — no network, no randomness, no input. It writes
exactly `rinoo9` (6 bytes, no trailing newline) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # rinoo9
```

Run it twice and the output is byte-identical.
